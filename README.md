# mochi — Portfolio

鏡面シルバーの花と月光をテーマにした、依存パッケージ不要の静的ポートフォリオ。

## 開発

Node.js 22以上で、既存のチェックアウトから実行します。

```sh
cd /workspace/portfolio
npm run dev
```

ポートは既定で3000です。`PORT`で変更できます。`npm run check`でJavaScriptの構文を確認できます。HTML・CSS・JavaScriptとassetsを配信する静的ホスティングにも配置できます。

## 編集

- 名前・紹介文・連絡先：`index.html`。連絡先は未設定です。設定後に準備中の表示を実際のリンクに差し替えてください。
- 作品詳細：`app.js`の`projects`と`index.html`の作品一覧。
- 配色・レイアウト・動き：`style.css`。
- `assets/moonflower.png`：このサイト用のAI生成ビジュアル。元画像は別途保存されています。

掲載作品は自主制作コンセプトです。プロフィール文も仮の文章なので、公開前に本人の内容に確認・差し替えしてください。実際のクライアント実績は記載していません。

アニメーション停止ボタン、OSの動きを減らす設定、キーボード操作、モバイル幅に対応しています。作品詳細はダイアログで開き、Escapeキーでも閉じられます。

## デザイン比較

画面下の OTHER WORLDS で4案を切り替えられます。既定は銀の花です。

- `?world=cyber`：青い記憶の端末
- `?world=angel`：堕天使のギャラリー
- `?world=higan`：電子の彼岸

選択はURLに反映され、戻る・進むでも切り替わります。背景の天使と銀の木はAI生成アートです。アニメーション停止はすべての案に適用されます。

既定のデザインは「海辺の記録」に更新しました。提供写真から加工した版画調イラストを、生成りの余白に縦長で配置しています。`?world=archive`でも選択できます。以前の銀の花は`?world=original`で閲覧できます。作品詳細にAI加工の旨を記載しています。

海辺の記録のトップは全画面表示です。PCは横に拡張したAI加工画像`coastal-wide.png`、スマホは縦長の`coastal-print.png`をpicture要素で使い分けます。比較パネルはDESIGN STUDIESから開閉できます。ゆっくりした拡大とマウス追従はMOTION OFFまたはOSの動きを減らす設定で停止します。

2.5D表示を追加しました。`coastal-clean.png`は木・車を取り除いたAI加工背景です。SVGで元画像から切り出した木と車を重ね、レイヤーごとに移動量を変えています。画面右下のVIEWでFLAT/2.5Dを比較できます。スマホはスクロール、PCはスクロールとマウスに反応します。MOTION OFFとOSの動きを減らす設定ではレイヤー移動を停止します。本格的な3Dモデルではないため、視点移動は小さな範囲に限定しています。
